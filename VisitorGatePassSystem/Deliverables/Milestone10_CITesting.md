### 3. Pipeline Integration Details

The `Jenkinsfile` was updated in Milestone 8 to include a specific stage for Selenium UI tests.

#### 3.1 The Test Stage

```groovy
stage('Selenium UI Tests') {
    steps {
        // We run specific UI tests here. If they fail, the pipeline fails.
        bat 'mvn test -Dtest=GatePassUITest'
    }
    post {
        always {
            // Archive screenshots on failure
            archiveArtifacts artifacts: 'screenshots/*.png', allowEmptyArchive: true
        }
    }
}
```

#### 3.2 Post-Build Actions

The post-build actions in the pipeline are configured to process the JUnit test result XML files generated by Maven Surefire.

```groovy
post {
    always {
        archiveArtifacts artifacts: 'target/*.jar', allowEmptyArchive: true
        junit 'target/surefire-reports/*.xml'
    }
}
```

### 4. Continuous Integration Workflow

1. **Developer Commits Code:** Code containing application changes and/or test changes is pushed to the repository.
2. **Pipeline Triggered:** Jenkins detects the commit and starts the pipeline.
3. **Build & Unit Test:** Basic compilation and fast unit tests run.
4. **Selenium Tests Run:** The `GatePassUITest` class executes against the locally spun-up Spring Boot application (on a random port).
5. **Evaluation:**
   - **If Tests Pass:** Pipeline continues to Docker Build and Deploy stages.
   - **If Tests Fail:** Pipeline halts. Deployment does **not** occur. Screenshots are captured and archived.
6. **Reporting:** Jenkins parses the JUnit XML and displays the test trend graph and detailed results on the job dashboard.

---

### 5. Simulating a Defect and Fix

To demonstrate the CI testing capability:

1. **Defect Introduction:** A deliberate change was made to `login.html` (e.g., changing the ID of the username field from `username` to `user_id`).
2. **Pipeline Failure:** Jenkins ran the pipeline. The Selenium test `testAdminLoginAndDashboard` failed because it could not find `By.id("username")`. The pipeline failed, and deployment was aborted. A screenshot of the failed login page was archived.
3. **Defect Fix:** The change in `login.html` was reverted. Code was pushed.
4. **Pipeline Success:** Jenkins ran the pipeline again. Tests passed, and the pipeline proceeded to deployment.
